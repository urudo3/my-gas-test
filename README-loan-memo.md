# 貸借記録メモ Pro - GitHub 連携ガイド

このアプリを GitHub Pages 等で公開し、Google スプレッドシートをデータベースとして利用するための設定手順です。

## 1. Google Apps Script (GAS) の準備

1.  スプレッドシートの「拡張機能」 > 「Apps Script」を開きます。
2.  `new_code.gs` の内容をコピー＆ペーストして保存します。
3.  **デプロイ** ボタンを押し、「新しいデプロイ」を選択します。
4.  種類の選択で「ウェブアプリ」を選びます。
5.  設定を以下のようにします：
    -   **次のユーザーとして実行:** 自分
    -   **アクセスできるユーザー:** 全員（匿名ユーザーを含む）※
6.  発行された **ウェブアプリのURL** をコピーします。

> [!IMPORTANT]  
> 「全員」にしないと、GitHub フロントエンドからの通信が認証エラーでブロックされます。

## 2. GitHub への設置

1.  リポジトリに以下の3ファイルをアップロードします：
    -   `loan-memo.html` (メイン画面)
    -   `loan-memo.css` (デザイン)
    -   `loan-memo.js` (ロジック)
2.  GitHub Pages を有効化し、`loan-memo.html` にアクセスします。

## 3. アプリの初期設定

1.  ブラウザで `loan-memo.html` を開くと、初回のみ「WebアプリURLを入力してください」と表示されます。
2.  手順1でコピーしたURLを貼り付けます。
3.  これで設定完了です！以降、GitHub上の画面からスプレッドシートに対して直接記録・集計が行えます。

---
### 備考
- データの保存先はスプレッドシートですが、フロントエンドを GitHub に置くことで、高速な動作とリポジトリによるバージョン管理が可能になります。
- 保存したURLはブラウザ（LocalStorage）に記録されます。別の端末で使う場合は再度入力してください。
